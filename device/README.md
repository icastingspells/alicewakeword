# Устройство и ручное управление

Основные инструкции находятся в [README](../README.md).
Поддерживаемый профиль: Lite 2 / Plum, прошивка
`0.369.1.46.4778258659.20261013.133`. Проверяются точные SHA-256 бинарника и launcher.
Для другой прошивки нужен анализ и отдельный профиль, а не отключение проверок.

## Файлы

- `/data/eva/releases/<id>` — неизменяемые релизы с контрольными суммами.
- `/data/eva/current` — атомарно переключаемая ссылка на текущий релиз.
- `/data/eva/previous` — ссылка на предыдущий релиз для восстановления.
- `/data/eva/config.env` — режим `observe` или `active`.
- `/data/eva/measurement.env` — результат замера, привязанный к движку и прошивке.
- `/etc/init.d/S98eva` — автозапуск перед штатным Quasar.
- `/tmp/eva` — сокет, PID и ограниченные журналы; исходный PCM не сохраняется.

Новая установка или смена модели сбрасывает режим в `observe` и отменяет старый замер.
Изменения ALSA, прошивки, штатных моделей и бинарника `maind` не требуются.
Подготовленный launcher подключается через bind-mount. После остановки EVA отвод
не ждёт получателя и не изменяет аудиобуфер Quasar.

## Команды в root shell колонки

```sh
/data/eva/current/evactl status
/data/eva/current/evactl mode observe
/data/eva/current/evactl measure
/data/eva/current/evactl mode active
/data/eva/current/evactl stop
/data/eva/current/evactl start
/data/eva/current/evactl disable
/data/eva/current/evactl enable
```

`measure` собирает 30 секунд PCM. Для допуска нужны не менее 300 кадров,
отсутствие потерь и максимум inference менее 80 мс. Это проверка в текущих условиях,
а не гарантия отсутствия задержек Linux при любой нагрузке.
В физических тестах наблюдались пики 107–137 мс при старте и диалоге без потерь PCM.
Смотрите статистику в `EVA_HEALTH` и `EVA_TRANSPORT`.

Первое подключение отвода требует перезагрузки Quasar/устройства. `start` сам
не перезапускает Quasar. После `disable` для повторного включения применяется `enable`.
При незавершённой проверке загрузки или трёх сбоях движка служба отключается.
Если при начальной проверке нет PCM, в том числе из-за mute, может потребоваться
включить микрофоны и выполнить `enable`.

## Активация и mute

Используется raw ALSA PCM до VQE: mic0 из потока 48 кГц × 3 канала, фильтр до 16 кГц,
OpenWakeWord mel/embedding и выбранный классификатор. Промежуточные свёртки для
перекрывающихся окон кэшируются без изменения математического результата.

Перед активацией проверяются IDLE в журнале и аппаратный `SW_MUTE_DEVICE` через
`EVIOCGSW` устройства gpio-keys. Проверка не читает события кнопок и не захватывает
их эксклюзивно. При mute или недоступном состоянии диалог не запускается.
Временный CLI получает фиксированные команды `s`/`x`; нативный ограничитель завершает
его при зависании. Зависимости от отсутствующего BusyBox `timeout` нет.

На физической Lite 2 подтверждены оба положения mute, распознавание живой «Ева»,
ответ Алисы и автозапуск после перезагрузки. При музыке и эхе требуется отдельная
оценка качества. Штатный споттер «Алиса» продолжает работать.

## Ручная распаковка и откат

Штатный BusyBox tar не поддерживает `-z`:

```sh
mkdir -p /data/eva-staging
cd /data/eva-staging
# Скопировать сюда архив доступным способом, предварительно проверив SHA-256.
gzip -dc alicewakeword-plum.tar.gz | tar -xf -
sh eva-plum/install.sh
sync
reboot
```

Удалить автозапуск и отключить EVA:

```sh
sh /data/eva/current/uninstall.sh
reboot
```

Уже загруженный preload полностью выгружается только после перезапуска Quasar
или перезагрузки. Сохранённые релизы не удаляются автоматически.

## Проверки реализации

- Численное сравнение всех трёх графов с исходными TFLite.
- 96 сравнений rolling-кэша с полным embedding, включая сброс истории.
- Проверки неизменности остальных задач Quasar и отказа при чужом preload.
- Проверки целостности архива, обхода путей и ошибок старого ADB в CI.
- Лабораторные ARM VM проверки установки, повторной установки, конфликтов,
  неизвестного mute, ограничителя CLI и удаления.
- Физические тесты PCM, живой речи, ответа, mute и перезагрузки.

Дампы и частные лабораторные журналы не входят в публичный репозиторий.
