# AliceWakeWord

Своя wakeword-модель **openWakeWord** на Яндекс Станции Lite 2 (Plum).
Проект добавляет распознавание «Ева» и вызывает штатный голосовой диалог Алисы.
Можно собрать пакет с другим совместимым `.tflite`-классификатором.

На колонке работают небольшой нативный AArch64-движок и ARM32-аудиоотвод.
Python, TensorFlow и TFLite runtime на устройство не устанавливаются.
Штатный споттер «Алиса» остаётся включённым.

## Совместимость

Проверены **Lite 2 / Plum** и прошивка
`0.369.1.46.4778258659.20261013.133`. Нужен уже настроенный root SSH или root ADB.
Получение root и изменение прошивки этот проект не выполняет.
Установщик проверяет точные хеши `maind` и `launch.json`, память и свободное место.
Для другой прошивки сначала нужен отдельный проверенный профиль; обхода проверки нет.

Проверено на физической колонке: пробуждение от «Ева», ответ Алисы,
аппаратный mute и автозапуск после перезагрузки. Пакет занимает около **2,17 МиБ**
в архиве и **2,82 МиБ** после распаковки. RSS детектора — примерно **3–4,6 МиБ**,
без учёта штатного Quasar и временного CLI при активации.
Трёхминутный прогон прошёл без потерь PCM; при старте и диалоге были пики задержки
выше 80 мс без потерь пакетов. Длительные тесты с музыкой и дальней речью ещё нужны.

## Быстрая установка

На компьютере нужны Python **3.12+** и `ssh` с уже работающей аутентификацией по ключу.
Для готового пакета никаких Python-библиотек дополнительно устанавливать не требуется.

```sh
git clone https://github.com/icastingspells/alicewakeword.git
cd alicewakeword

# Загрузить последний релиз, проверить устройство, ничего не устанавливать.
python alicewakeword.py install --host 192.168.1.50 --check

# Установить в режиме наблюдения и перезагрузить для подключения аудиоотвода.
python alicewakeword.py install --host 192.168.1.50 --reboot
```

Замените адрес своим. SSH-порт по умолчанию **2222**, другой задаётся через `--port`.
Скрипт использует передачу через stdin SSH: **SCP и SFTP на колонке не нужны**.
Архив и его SHA-256 скачиваются из [Releases](https://github.com/icastingspells/alicewakeword/releases).
Можно передать локальный пакет: `install --host HOST --package path/to/package.tar.gz`.
Классификатор `eva.tflite` для воспроизведения стандартной сборки также приложен к релизу.

После восстановления связи:

```sh
python alicewakeword.py status --host 192.168.1.50
python alicewakeword.py activate --host 192.168.1.50
```

`activate` сначала включает наблюдение и проводит 30-секундный замер.
При потерях PCM или недостаточной скорости активный режим не включается.
При успехе произнесите «Ева», дождитесь индикации прослушивания и задайте вопрос.
Положение аппаратного mute проверяется перед каждым вызовом диалога.

### Через ADB

ADB должен быть установлен, подключён к колонке и предоставлять root shell:

```sh
adb connect 192.168.1.50:5555
python alicewakeword.py install --adb 192.168.1.50:5555 --check
python alicewakeword.py install --adb 192.168.1.50:5555 --reboot
```

Путь к ADB задаётся через `--adb-path`. Старый adbd может скрывать коды ошибок:
установщик проверяет отдельный маркер выполнения каждой команды.
После перезагрузки сетевой ADB может отключиться — тогда используйте SSH.

## Управление и удаление

```sh
python alicewakeword.py status   --host HOST
python alicewakeword.py stop     --host HOST  # остановить до следующего запуска
python alicewakeword.py start    --host HOST
python alicewakeword.py observe  --host HOST  # детектор без запуска диалога
python alicewakeword.py activate --host HOST  # замер и включение активации
python alicewakeword.py disable  --host HOST  # отключить, включая автозапуск
python alicewakeword.py enable   --host HOST  # включить после disable
python alicewakeword.py uninstall --host HOST
python alicewakeword.py reboot   --host HOST # полностью выгрузить аудиоотвод
```

Архив устанавливается в `/data/eva/releases/<id>`, текущий релиз — `/data/eva/current`.
Исходные бинарники, ALSA и модели Яндекса не заменяются. Конфигурация запуска
подключается через bind-mount; добавляется один init-скрипт `S98eva`.
Предыдущие релизы сохраняются для восстановления.
После `disable` для повторного включения выполните на колонке
`/data/eva/current/evactl enable`; затем при необходимости перезагрузите её.

## Другая TFLite-модель openWakeWord

Модель загружается **на компьютер сборки**, а не в штатный TFLite Яндекса.
Скрипт преобразует граф в C, проверяет численную эквивалентность и создаёт новый пакет.
На колонке используется одна пользовательская модель за раз.

Требования к классификатору:

- Один вход `float32 [1,16,96]` и один выход вероятности `float32 [1,1]`.
- Признаки совместимы с frontend openWakeWord v0.5.1: mel → embedding.
- Операции поддерживаются нашим AOT-экспортёром. Неподдерживаемые графы отвергаются.
- Модели microWakeWord, raw-audio, int8 и модели с другим frontend не взаимозаменяемы.

```sh
# Один раз: venv с LiteRT/NumPy и Zig 0.15.2. Инструменты скачиваются на компьютер.
python alicewakeword.py setup

# Сборка, проверка и упаковка собственной модели.
python alicewakeword.py build --model /path/to/my_wakeword.tflite --threshold 0.5

# Установка полученного пакета.
python alicewakeword.py install --host HOST --package dist/alicewakeword-plum.tar.gz --reboot
python alicewakeword.py activate --host HOST
```

В PowerShell можно использовать `py -3.12` вместо `python`.
Если Zig уже установлен, задайте `ALICEWAKEWORD_ZIG` или добавьте его в PATH.
Сборка закреплена на версии 0.15.2. Проверенный хост сборки — Windows x64;
переносимый CLI и тесты также запускаются в Linux CI.

Результат: `dist/alicewakeword-plum.tar.gz`, файл SHA-256 и `dist/package.json`
с хешем выбранной модели. Новый пакет всегда возвращается в `observe` и требует
нового замера перед активацией. Исходная модель не перезаписывается, а пользовательские
модели, артефакты сборки и локальный кэш не попадают в Git.

## Как устроено

```text
Quasar snd_pcm_readi → неблокирующий ARM32 ALSA-отвод → Unix socket
  → mic0, фильтр 48→16 кГц → openWakeWord mel → embedding → выбранный classifier
  → порог + подавление повторов → IDLE/mute guard → штатный maind --cli
```

NEON, три вычислительных потока и точный кэш перекрывающихся окон сокращают нагрузку.
96 сравнений кэша с полным графом дали нулевое расхождение. Экспортёр проверяет
три графа против LiteRT. Отвод не открывает второй захват и не записывает PCM на диск.
При сбое служба ограничивает перезапуски, а повреждённые пакеты и чужой preload
отклоняются. Из-за raw PCM до VQE возможны ограничения качества при музыке и эхе.
